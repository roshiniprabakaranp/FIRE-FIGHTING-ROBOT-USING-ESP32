 FIRE FIGHTING ROBOT USING ESP32

 Project Overview
A Fire Fighting Robot using ESP32 is designed to detect fire using a flame sensor and activate a DC fan through a relay module.

 Components Used
- ESP32
- Flame Sensor
- Relay Module
- DC Fan
- Robot Chassis

 Simulation
The circuit has been designed and tested using Cirkit Designer. Simulation screenshots and circuit files will be added to this repository.

 Project Status
- Circuit Simulation: Completed
- Real-Time Hardware Implementation: In Progress

 Objective
To detect fire and activate a firefighting mechanism using an ESP32 microcontroller.
